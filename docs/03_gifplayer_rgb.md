# ESP32-S31 GIF Player + RGB LED Sync

基于 **ESP32-S31** 与 **LVGL 8.x** 的 GIF 动图播放器，配备 WS2812 RGB LED 颜色同步、ADC 按键控制、HUD 仪表盘等交互功能。

---

## 硬件要求

| 组件 | 型号/规格 |
|------|-----------|
| SoC | ESP32-S3 (ESP32-S31-Korvo 开发板) |
| LCD | ST7262E43, 800×480 RGB565 并行接口 |
| 触摸 | GT1151 (I2C) |
| LED | WS2812 RGB LED (单像素, RMT 驱动) |
| 按键 | ADC 按键阵列 (GPIO42, 电压分压检测) |
| PSRAM | 必须 (GIF 帧缓冲 + LVGL 显示缓冲) |

### 引脚定义

| 功能 | GPIO | 备注 |
|------|------|------|
| **LCD RGB565** | GPIO8~36 (16 位并行) | 详见 `bsp_board.h` |
| LCD 行同步 | GPIO44 | — |
| LCD 场同步 | GPIO45 | — |
| LCD 数据使能 | GPIO43 | — |
| LCD 像素时钟 | GPIO40 | — |
| 触摸 I2C SDA | GPIO0 | — |
| 触摸 I2C SCL | GPIO1 | — |
| WS2812 LED | GPIO37 | RMT TX, 10MHz |
| ADC 按键 | GPIO42 | 4 按键分压阵列 |

### 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| **main** | `main.c` | 系统初始化编排，按顺序启动 LCD → 触摸 → LVGL/UI → LED → 按键 → 业务逻辑 |
| **app_ui** | `app_ui.c/.h` | LVGL 图形界面：暗角背景、GIF 播放器、控制面板、RGB 按钮、色环、HUD、速度徽章。所有 UI 指针内部封装 |
| **app_logic** | `app_logic.c/.h` | 业务调度胶水层：从按键队列读取事件 → 调用 hal_led/app_ui 接口。唯一"知道所有模块"的地方 |
| **hal_led** | `hal_led.c/.h` | WS2812 LED 硬件抽象：RMT TX 驱动、状态机 (on/off/模式/亮度)、RMT 互斥锁防竞态 |
| **hal_key** | `hal_key.c/.h` | ADC 按键硬件抽象：ADC 初始化、周期性扫描、消抖、短按/长按分类、队列发送 |
| **hal_display** | `hal_display.c/.h` | 显示子系统：RGB LCD 初始化、GT1151 触摸初始化 (I2C 总线复用) |
| **bsp_board** | `bsp_board.h` | 纯宏头文件：引脚定义、屏幕尺寸、布局常量、LED/按键参数 |
| **led_strip_encoder** | `led_strip_encoder.c` | WS2812 RMT 编码器 (来自 ESP-IDF 示例) |

### 任务划分

| 任务 | 优先级 | 栈大小 | 职责 |
|------|--------|--------|------|
| `LVGL` | 4 | 8192 | LVGL 图形渲染、定时器回调、事件处理 |
| `hal_key` (扫描) | 5 | 4096 | ADC 按键扫描、消抖、事件发送 |
| `app_logic` (业务) | 5 | 4096 | 按键事件处理、LED/UI 调度 |

## 功能特性

### 1. GIF 动图播放
- 3 组内嵌 GIF 动图 (编译时链接)
- 播放/暂停切换
- 动图切换 (◄/► 按钮或 SET 短按)
- PSRAM 缓冲解码

### 2. GIF→LED 颜色同步
- 实时采样 GIF 当前帧，降采样至 ~20×24 网格
- 5-bit 直方图统计主色调
- WS2812 LED 按主色调呼吸发光 (2.5s 正弦周期)
- 屏幕色环同步指示当前追踪颜色
- 颜色缓动插值 (~600ms 满量程过渡)

### 3. RGB 按钮手动控制
- 红/绿/蓝三个按钮可直接设置 LED 颜色
- 按下后自动关闭 GIF→LED 同步
- 按 MODE 键重新开启同步
- 按钮附带涟漪水波纹动效 + 缩放反馈

### 4. GIF 播放速度调节
- VOL+ 长按：加速 1.0x → 1.5x → 2.0x
- VOL- 长按：减速 1.0x → 0.5x → 0.25x
- MODE 长按：重置为 1.0x
- 速度徽章弹出显示 (0.8→1.0 缩放动画)，1.5s 后淡出
- 慢速 (<0.8x) 蓝色 / 正常 灰色 / 快速 (>1.3x) 橙色

### 5. HUD 系统仪表盘
- **FPS**：实时帧率 (平滑滤波)，绿色/黄色/红色指示
- **MEM**：PSRAM 使用量 (MB)，绿色/黄色/红色指示
- **TEMP**：CPU 内部温度，绿色/黄色/红色指示
- 更新频率：500ms

### 6. LED 状态管理
- 3 种颜色模式 (红/绿/蓝)
- 亮度 0-255 可调
- SET 长按开关 LED
- VOL± 短按步进调节亮度

## 按键映射

| 按键 | 短按 | 长按 (≥1s) |
|------|------|------------|
| **SET** | 切换 GIF 播放/暂停 | LED 开关 |
| **MODE** | 切换 LED 颜色模式 (红→绿→蓝) | 重置：模式=红、亮度=80%、速度=1.0x、重开同步 |
| **VOL-** | 亮度减 (-20) | GIF 减速 (2.0→1.5→1.0→0.5→0.25) |
| **VOL+** | 亮度加 (+20) | GIF 加速 (0.25→0.5→1.0→1.5→2.0) |

### ADC 按键电压参考

| 按键 | 原始 ADC 值 | 分档范围 |
|------|-------------|----------|
| SET | ~315 | < 600 |
| MODE | ~848 | 600~1150 |
| VOL- | ~1371 | 1150~1600 |
| VOL+ | ~1815 | 1600~2300 |
| 空闲 | ~0 / >2300 | — |

## 关键设计要点

### RMT 互斥锁
`gif_color_track_cb` (LVGL 任务) 与按键任务同时访问 WS2812 RMT 通道时存在竞态。使用 `xSemaphoreCreateMutex()` 保护 `led_hw_set_rgb()` 的 RMT 收发操作。

### LVGL 跨任务锁策略
`app_logic` 任务调用 LVGL 接口时使用 `lvgl_port_lock(pdMS_TO_TICKS(100))` — 带超时的阻塞锁。避免与 LVGL 任务形成互锁死锁 (100ms 超时确保不会永久阻塞)。

### 多任务互锁防护
LVGL 锁和 RMT 锁双锁场景：LVGL 任务持 LVGL 锁等待 RMT 锁时，按键任务最多等待 100ms 获取 LVGL 锁即放弃，避免死锁传播。

### GIF 速度调速
获取 GIF 帧间隔 (delay_cs × 10ms) 作为基准周期，调速时按倍率缩放 `lv_timer_set_period()`，下限 10ms。

### PSRAM 使用
- GIF 文件数据缓冲区 (PSRAM)
- LVGL 显示缓冲区 (PSRAM + DMA)
- 渐变背景像素缓冲 (PSRAM)

## 构建与烧录

### 环境要求
- ESP-IDF v6+ (推荐 master)
- 启用了 PSRAM (Quad/Octal SPI, 8MB)
- LVGL 8.x (通过 IDF 组件管理器安装: `lvgl` + `esp_lvgl_port`)

### 构建步骤

```bash
# 设置目标芯片
idf.py set-target esp32s31

# 配置 (如需)
idf.py menuconfig

# 编译
idf.py build

# 烧录
idf.py -p PORT flash monitor
```

### Kconfig 关键配置
- **PSRAM**: `Component config → ESP PSRAM → Quad/Octal SPI PSRAM`
- **LVGL**: `Component config → LVGL Configuration` (使用组件默认配置即可)
- **Task WDT**: 建议保持开启 (默认 5s 超时，本项目的 100ms 锁超时不会触发)

### 添加新的 GIF 动图

1. 将 GIF 文件放入 `main/gif/` 目录
2. 在 `main/CMakeLists.txt` 中添加 `target_add_binary_data(${COMPONENT_LIB} "gif/your_file.gif" BINARY)`
3. 在 `main/bsp_board.h` 中添加链接器符号: `extern const uint8_t _binary_your_file_gif_start[];` 和 `_end`
4. 在 `main/app_ui.c` 的 `gif_list[]` 中添加条目
